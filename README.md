# y2v.world

A Jekyll-based blog exploring the intersection of impact, public policy, Vedanta, and emerging technologies.

## About

y2v.world is a platform dedicated to discussing Yukti Vijnana - a pragmatic approach to knowledge and wisdom, inspired by Swami Vivekananda's concept of Practical Vedanta. The site explores how this philosophy can be applied to modern challenges, particularly in the context of emerging technologies like AI.

## Getting Started

### Prerequisites

- Ruby version 2.5.0 or higher
- RubyGems
- GCC and Make

### Installation

1. Install Jekyll and Bundler:
   ```
   gem install jekyll bundler
   ```

2. Clone this repository:
   ```
   git clone https://github.com/yourusername/y2v.world.git
   cd y2v.world
   ```

3. Install dependencies:
   ```
   bundle install
   ```

4. Build and serve the site locally:
   ```
   bundle exec jekyll serve
   ```

5. Browse to http://localhost:4000

## Deployment on GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`
2. Push this repository to GitHub:
   ```
   git remote add origin https://github.com/yourusername/yourusername.github.io.git
   git push -u origin main
   ```
3. Your site will be available at `https://yourusername.github.io`

## Customization

- Edit `_config.yml` to change site settings
- Add new posts in the `_posts` directory
- Modify layouts in the `_layouts` directory
- Update styles in `assets/css/main.scss`
